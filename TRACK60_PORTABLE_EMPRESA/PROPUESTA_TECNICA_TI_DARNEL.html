1. Resumen Ejecutivo

El proyecto TRACK60 es una plataforma corporativa desarrollada para auditar, gobernar y registrar en tiempo real el cumplimiento del trabajo estandarizado (Standard Work), la supervisión 5S y los planes de acción (ProPlanes) en las plantas de Extrusión, Termoformado, Inyección y Litografía de Grupo Darnel.

La aplicación ya está operativa y validada multiplataforma (Web en navegadores de PC, APK nativo en Android y PWA instalable en iOS/iPhone). El objetivo de este documento es solicitar a TI la habilitación de los permisos delegados en Microsoft Entra ID (Azure AD) y Microsoft Graph API para conectar la aplicación directamente con las listas de SharePoint ya existentes.

3. Estándares de Seguridad y Mínimo Privilegio (Zero Trust)

Cumplimiento de Seguridad Informática: La aplicación nunca almacena ni procesa contraseñas de los usuarios. Todo el flujo se delega a los servidores oficiales de inicio de sesión de Microsoft (OAuth 2.0 con PKCE).
  • Protocolo Estándar: OAuth 2.0 con Authorization Code Flow with PKCE (RFC 7636), recomendado formalmente por Microsoft para aplicaciones Single Page (SPA) y móviles.
  • Aislamiento Estricto: La aplicación solo tendrá acceso a las listas asociadas al proyecto TRACK60 mediante permisos Sites.Selected, sin visibilidad sobre otros sitios, carpetas ni correos institucionales.
  • Tokens Cifrados: Utiliza tokens JWT de corta duración emitidos y firmados directamente por el tenant de Grupo Darnel.

4. Solicitud Específica para el Equipo de TI de Darnel

Para completar la vinculación, se requiere la creación de un App Registration en el portal de Microsoft Entra ID con los siguientes parámetros:

A. Configuración del Registro de Aplicación

• Nombre: TRACK60 - Grupo Darnel
• Tipo de Cuentas: Solo las cuentas de este directorio organizativo (Single Tenant - Darnel Group).

B. Permisos Delegados de Microsoft Graph API

• User.Read: Lectura del perfil básico del colaborador (Nombre, cargo, correo).
• Sites.Selected: Acceso de lectura/escritura restringido exclusivamente al sitio de TRACK60.

C. URIs de Redirección (Redirect URIs)

• Plataforma Web (PC / PWA): http://localhost:8080/ (Pruebas) y URL interna de producción.
• Plataforma Android: msauth://com.darnel.track60/

D. Parámetros a Entregar al Equipo de Proyecto

• Application (Client) ID
• Directory (Tenant) ID
• URL o Site ID del sitio de SharePoint asignado.

5. Impacto Operativo Directo

  • Visibilidad en Tiempo Real: La gerencia de operaciones y los jefes de planta visualizan en vivo el cumplimiento de cada línea sin esperar al cierre de turno.
  • Cero Papel y Auditoría Fotográfica: Las tareas críticas incorporan fotos de antes y después aprobadas por supervisión técnica.
  • Cero Mantenimiento para TI: No requiere servidores dedicados, bases de datos externas ni soporte de infraestructura adicional.
